Burgers equation is used as the canonical equation for both STENCIL-NET and weak SINDy. 

## Some background on autoregressive model discovery 
The difficult and interesting problem when determining the underlying dynamics given some data is that observed data is always limited to the specific recording environment.
More specifically, it is not possible to measurement smoothly across every point in space for an infinitely fine time resolution - observation is necessarily coarse.
In my synthetic data generation, I simulated the data on a fine grid and defined the observations as a coarsely sampled data - x20 (time) and x4 (space). 

Another feature of measurement is that dynamical equations (i.e. PDEs) describe how u_t (du/dt) evolves over time, but u_t is not directly observable.
You can nonetheless infer the instantenous value of u_t (e.g. central spacing), and methods such as strong SINDy does precisely this on data with 0 noise. 
Strong SINDy treats PDE discovery as a linear regression problem. Given $$du/dt = sum_i A_i*\phi_i$$, where $$\Phi$$ is a dictionary of hand-crafted base functions $$\phi_i$$ - i.e. $$\Phi = {\phi_1, ..., \phi_k}$$, find $$A_i$$ by gradient descent. 

Problem arises with data with even minimal amount of noise because directly computing du/dt instantaneously from noisy data is unstable without any smoothing. 
Weak SINDy improves performance drastically on noisey data by integrating the data over dt using some integration assumptions. Integration here essentially works to "smoothen" the data in the presence of noise. 
But some assumption needs to be made in order to construct such integrating operator on discrete data. 

The exact choice of you integrating operator however affects performance as they carry different biases.

Without knowing what the underlying dynamics is nor its noise structure, you would have to experiment with different integration methods to determine which method produces the best fit. 

Identifying the problem of coarse measurement and noisy data as key, STENCIL-NET aims to overcome this problem by not explictly deriving an equation like SINDy.
Instead, it finds a small MLP that corresponds to a discrete propagator T where u(t+1) = T(u(t)). Bolstered by theoretical result that any rational function can be expressed as an MLP, the authors claim 
that STENCIL-NET is a more appropriate way to discover the underlying dynamics from real data where problems of measurement and noise are inherent. 
Indeed, my further analysis shows that, although weak SINDy helps overcome small leveels of noise, it nonetheless struggles to find the ground truth dynamical equation with increasing coraseness of measurement. 

Something I am not so sure about - characteristics of emergent dynamics is clearly scale dependent, and therefore measurement dependent. Therefore, it is probably true that appraoches like SINDy which tries to explicitly derive equations will not be able to uncover the underlying dynamical equation under conditions of large enough coarseness, which is probably the realistic regime for real world problems. 
Therefore, is there any point in deriving equations? Even if we discover an equation, if they are scale dependent, do we learn anything? My answer right now is - I don't know, but probably. But more importantly, STENCIL-NET as an alternative is certainly much less interpretable. Therefore, even if the ground truth dynamical equation is not recoverable under measurement conditions, I think there is still reason to look for an equation if we are interested in finding interpretable results. 

### Dynamical equation vs propagator 
For the purpose of EDGAR, we are going to continue pushing towards discoverying equations for now rather than MLP's. 
This still leaves us with two choices for the type of equation that we instruct EDGAR to identify. 
We can either ask EDGAR to 
- 1. Come up with a propagator equation f where u(t) = f(u(t-1), ..., u(t-m))
- 2. Come up with the RHS function of a PDE (i.e. f where du/dt = f(u, t)) and an integration method (e.g. forward Euler) 

I've decided to go ahead with 2 because 
- PDE is much more interpretable for understanding dynamics than the first option 
- 2 should be just as expressive as 1
- Asking the LLM to choose the integration method should hopefully help us avoid the biases that come with different integration method
