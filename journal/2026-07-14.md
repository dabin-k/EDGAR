## Done — v2 rebuilt around the scalar map

**The ground truth as first written was degenerate, and this was the important finding.** With
`A∈[0.7,1.5], q∈[0.1,0.3]` the fixed point at x=0 has slope `f'(0) = A·q ≤ 0.44 < 1`, so it is
globally attracting: every cell collapses to the noise floor within ~4 steps (rms 1.36 → 0.28 →
0.056 → 0.021 → 0.005 = the process noise). Only block 0 carries any signal, and since train blocks
are [0,2,4] and test blocks [1,3], **the entire test split was pure noise** — the winning model would
have been `return 0`, and the cos·sin nonlinearity would never have been exercised.

Root cause is general, and worth remembering for any future 1-D map: a scalar map whose attractor is
a *fixed point* is useless for equation discovery, because the trajectory only ever visits one x and
the shape of f there is indistinguishable from its tangent line. The trajectory has to *explore* the
function for the function to be identifiable. Both failure modes bite:
- `A·q < 1` → collapse to x=0, data is noise.
- `A·q > 1` but mildly → settles on a *non-zero* fixed point; data is a constant plus noise, and an
  affine AR(1) (the local linearization) is essentially exact. Also useless.

Fix: keep the functional form, move to the **chaotic** regime `A∈[1.8,2.5], p∈[1.5,3.0], q∈[1.5,2.0]`
and discard a 200-step burn-in so every block is drawn from the same stationary distribution. 27/32
cells have a positive Lyapunov exponent; signal std 0.84. Verified on the **held-out test split** of
the real loader:

| model | params | test MSE | × noise floor |
|---|---|---|---|
| persistence | 0 | 0.489 | 19600× |
| affine AR(1) `a·x+b` | 2 | 0.498 | 19900× |
| linear AR(20) + intercept | 21 | 0.408 | 16300× |
| poly deg 9 in x(t) | 10 | 0.0027 | 110× |
| **truth `A·cos(px)·sin(qx)`** | **3** | **0.000024** | **1.0×** |

The truth sits exactly at the noise floor and nothing else is close, so there is a large gradient for
evolution to climb, and the seeds start at ~0.49.

**A positive Lyapunov exponent independently justifies dropping the rollout** — multi-step error
amplifies exponentially, so a rollout loss would measure the Lyapunov exponent more than the model.

### This dissolves the v3 estimator/GD pathology
`journal/2026-07-14_synthetic_data_v3.md` documents a trap where the estimator's closed-form one-step
fit was a stationary point of the *3-step* loss, so gradient descent was vestigial for exactly the
programs that got the estimator right. The new design removes it on both counts: the loss **is** the
one-step objective (no mismatch between what the estimator targets and what is scored), and the truth
is **nonlinear in its parameters** (p, q live inside cos/sin), so no closed form exists and gradient
descent does real work. Note this is a property of the new benchmark, not a fix for v3.
