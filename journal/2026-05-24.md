## Decisions

- **Option C for temperature compat** (per-provider rescale at the call boundary, not at the schedule). Preserves Gemini dynamics exactly so any prior Gemini baselines stay comparable; gives Anthropic a sensible mapped range without touching `task_spec.schedule()`.
- **`scripts/` for human diagnostics, `tutorials/` for pipeline walkthroughs, `tests/` for assertions.** Three-folder pattern: `scripts/` for quick standalone tools (e.g. `ping_llms.py`, `check_loader.py`), `tutorials/` for didactic step-by-step files anchored on a specific project (e.g. `walkthrough_orientation_tuning.py`), `tests/` for automated assertions (`tests/system/fake_runner.py` is the mold).
- **Per-field comments on TaskSpec.** Comments restating types are normally banned (CLAUDE.md), but the user is the audience this file is meant to teach. Comments focus on intent/usage, not type.
