However, there is no guarantee that the dataset you are using is well curated. Suppose that you are working with a dataset that contains cell activity over time, but 
it is possible that there is genuinely no single model that well describes the activity of all the cells you've recorded.
We usually try to overcome this by manually preprocessing the data and, for example, only selecting cells that are responsive to a particular stimuli set we are interested in.

The aim of this branch is to do some exploratory analysis. We want to see if we can use some naive clustering method to identify meaningful clusters within a measured 
population and run EDGAR in parallel for the multiple different clusters identified. The output would be to check if clustering helps us identify more predictive 
models that are also interpretable.

Rough results (naive KMeans, k=4, tuning curves L2-normalized → PCA-20):
- **Within-method stability is OK** (subsample ARI: Stringer 0.68, Jacob 0.80) **but
  cross-method is not** — KMeans vs Ward agree only ARI≈0.20 (Stringer) / 0.33 (Jacob).
- **Huge normalization sensitivity**: L2-shape vs raw-amplitude clusterings are basically
  unrelated (ARI 0.02); L2 vs z-score ARI 0.40. The "clusters" depend heavily on the feature.
- Silhouette rises monotonically with k (no peak) → tuning space looks like a **continuum**,
  not discrete natural kinds.
- **Spontaneous ≠ functional**: cells clustered on `spont_u` show ~zero agreement with
  tuning-curve clusters (ARI 5e-4, NMI 7e-4). Spontaneous structure does not predict tuning here.

Interpretation (tentative): naive clustering imposes cuts on a smooth manifold rather than
finding robust sub-populations. The open question is whether the per-cluster *mean tuning
curves* are still qualitatively distinct enough (unimodal vs bimodal, sharp vs broad) to make
per-cluster EDGAR worthwhile — that's an eyeball call on the notebook plots, not settled by
the metrics. Clean-ish negative on the "cluster on spontaneous alone" idea.
