## Done: ground-truth model for the Burgers AR task

The task asks for a discrete map `u(t) = f(u(t-1), u(t-2))` on the coarse sensor
field of the **unforced** viscous Burgers eq `u_t = -u u_x + D u_xx` (D=0.02, L=2π).

**No exact closed-form map exists**, for two independent reasons:
- the exact one-step map is the flow map over `dtc=0.04` — no finite closed form;
- ×4 space-coarsening makes the coarse field **non-Markovian** (a 2nd lag carries
  sub-grid info). This is why `MAX_LENGTH=2` and why the LS floor sits above zero.

**Best explicit surrogate** (method of lines: forward-Euler in time, central space):

```python
u_i(t) = u_i(t-1) + a * u_i*(roll(u,-1)-roll(u,1)) + b * (roll(u,-1)-2u+roll(u,1))
#            persistence      advection (-u u_x)          diffusion (u_xx)
```
with physical constants `a = -dtc/2h ≈ -0.204`, `b = dtc*D/h² ≈ 0.083`
(h = dxc = 2π/64 ≈ 0.0982). These are absorbed as free params in sensor-index space.

Verified numerically on the actual unforced coarse field (`scratchpad/verify.py`,
1-step MSE):
| model | 1-step MSE |
|---|---|
| persistence (model1) | 4.97e-6 |
| derived map, **fixed** a=-0.204, b=0.083 | 2.33e-7 |
| same form, LS-fit a,b | 1.16e-7 |

LS recovers a=-0.216 (≈ physical) but **b=0.127 ≫ 0.083** — the inflation is
partly sub-grid closure and partly the forward-Euler time-truncation bias (below).

**Second lag → AB2.** The principled use of the extra lag is a higher-order time
integrator: with `g(u) = a*adv + b*lap`,
`u(t) = u(t-1) + 1.5 g(u(t-1)) - 0.5 g(u(t-2))`. Cuts time error O(dt²)→O(dt³).

### Integration-scheme bias notes
- **Forward Euler is directionally biased**, not just noisy: 1st-order, and its
  modified equation is *anti-diffusive* (advection term contributes `-(dt/2)u²u_xx`),
  so the fit must inflate `b` to compensate. It's also conditionally unstable (FTCS).
- **Lax–Friedrichs** does *not* change the model structure — LF = FTCS + a fixed
  numerical Laplacian of coeff 0.5 (index space), i.e. `D_num = h²/2dtc ≈ 0.12 = 6×`
  physical D. It flips the bias to strongly *over*-diffusive: the fixed LF oracle
  (b_eff=0.583) scores 1.74e-5, **worse than persistence**. But because `b` is fit
  freely, LF and FTCS collapse to the same fitted model (a=-0.216, MSE≈1.2e-7). Scheme
  choice only moves the no-fit starting point, not the discoverable optimum. LF would
  only be the honest ground truth for the *forced/shock-forming* field (stability
  matters there; here the field is smooth so LF's smearing only hurts).

## Reference: protocol for choosing an integration algorithm (discovery tasks)

Choosing the integrator = choosing an **estimator**: scheme + measurement grid +
noise model + fitting objective are one coupled choice. Three failure modes:
(1) **representation** — scheme can't reproduce the flow over `dt`; (2) **bias/aliasing**
— truncation error masquerades as a library term and is absorbed into that coefficient;
(3) **mis-specification** — deterministic integrator for stochastic dynamics.

**Key quantitative gate:** compare the scheme's truncation error at your `dt` to the
noise floor (cross-trial std). Truncation ≪ noise → integrator only needs to be
*stable* (cheapest stable scheme; order/bias invisible). Truncation ≳ noise →
integrator bias dominates parameter estimates → raise order / orthogonalize / refine.

**Staged questionnaire** (Q → measure from data → decide):

1. **Is `dt` Markovian?** — spectrum near Nyquist, autocorr time in samples, `|Δx|/range`.
   - `dt ≪ τ_fast` → any consistent one-step explicit map.
   - `dt ~ τ_fast` → higher order **and/or extra lags** (non-Markovian; one lag can't be exact).
   - `dt > τ_fast` (aliased) → one-step ill-posed → **delay embedding** / latent substeps.
2. **Stiff?** — timescale spread; fast transients decaying in a couple samples; one-step
   Jacobian spectral radius >1 at LS params. → not stiff: **explicit**; stiff:
   **implicit / IMEX / exponential**.
3. **Geometry?** (prior knowledge) — constant amplitude over many periods (conservative)
   → **symplectic / implicit-midpoint**; sharp fronts/transport → **upwind/flux-limited
   conservative**; smooth dissipative → **central explicit**; driven → include forcing if
   measured+aligned, else restrict to autonomous epochs / co-estimate forcing.
4. **Noise?** (variance measurable, distribution unknown) — three reads:
   - variance grows with horizon (process/chaos) vs flat in time (measurement);
   - variance scales with amplitude (multiplicative) vs constant (additive);
   - residual lag-1 autocorr: white (obs noise) vs colored (model error / colored process).
   → measurement-noise-limited: **weak/integral form** or smoothing+collocation, avoid
   finite-difference derivatives; process noise: **SDE integrator** (Euler–Maruyama additive,
   Milstein multiplicative) + fit **moments/likelihood**, not trajectory MSE.
5. **Truncation aliases a model term?** — write the scheme's modified equation, check if its
   leading error ∈ library (Euler→diffusion, centered→dispersion, LF→u_xx). If it hits a
   **target** coeff → raise order / choose even-order-error scheme / refine. If it hits a
   **free nuisance** coeff → benign, ignore (why LF≡FTCS when fitted).
6. **Objective?** — default **multi-step rollout** (H ≈ few × τ; exposes drift/instability);
   measurement-noise-limited → **weak/integral form**; one-step only as a cheap screen.

Through-line: stability from Q1–3, bias from Q5 + the noise-floor gate, mis-specification
from Q4. Run in that order and the scheme falls out.
